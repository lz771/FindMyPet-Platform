# FindMyPet Platform
A web application that provides a platform for pet owners to share information for their lost pet by completing a lost-pet report form on the Report Lost-Pet page. The submitted reports will be displayed on the Lost-Pet Gallery page, allowing other users to view lost-pet cases in their local area.
